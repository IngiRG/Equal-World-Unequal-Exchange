# Empirical release checklist

A release is publishable only if all items pass.

- [ ] EXIOBASE record/version/year and archive checksum pinned.
- [ ] World Bank indicator IDs, year and retrieved snapshots recorded.
- [ ] EXIOBASE factor-input and hours rows resolved unambiguously.
- [ ] Country/region concordance reviewed; no silent RoW allocation.
- [ ] Monetary units and hours units converted explicitly.
- [ ] Compensation conservation passes numerically.
- [ ] Price-system residuals are below tolerance.
- [ ] No negative/non-finite output denominators enter unit coefficients.
- [ ] Baseline normal-return/non-labor-VA assumption named.
- [ ] At least three productivity/equivalence variants reported.
- [ ] Missing-country handling reported.
- [ ] Country, sector and global totals reconcile.
- [ ] Static results are not described as historical causal estimates.
- [ ] Website manifest identifies every source and specification.
